# 萱草花 · 引导式学习提示词

把提示词和学习任务发给聊天模型。模型会给一条有用的线索，问一个问题，等孩子回答再继续。

- **做题或练知识点**　[复制全科引导](guided-learning.md)
- **构思作文或看自己的草稿**　[复制写作引导](writing.md)

新开一个对话，复制所选文件里的完整文本块。在同一条消息末尾加上题目、知识点或写作任务，再发送。可以附上年级和已经想到哪一步。发照片前先遮住姓名、学校等个人信息。

```text
年级（选填）
题目和材料 / 想练的知识点 / 写作任务
我已经想到或写到哪里（选填）
```

## 可选的学科补充

全科引导已经能按学科选方法。想把某一科的引导说得更细，就把对应补充放在全科引导和题目之间，随同一条消息发送。

[数学](subjects/math.md) · [语文](subjects/chinese.md) · [英语](subjects/english.md) · [科学与理科](subjects/science.md) · [史地与道法](subjects/humanities.md)

## 提示词来源

做题的引导、出练习和判分原则来自萱草花 App。数学、语文、英语沿用 App 的教学重点，科学与理科、史地与道法是给对话版补写的。写作版把构思和段落反馈放进了一份提示词。App 有额外的题面检查和判分逻辑，聊天里的表现会随模型变化。
